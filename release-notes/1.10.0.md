## What's new in Fuse for macOS 1.10.0

### Emulation core improvements:
* Improve automatic detection and acceleration of custom tape loaders, preserve tape signal state when switching from ROM traps, and stop automatically restarting tapes at end of tape (Fredrick Meunier).
* Correct tape-loading sound through the beeper and handle unusual tape flag blocks (Fredrick Meunier).
* Refuse to save classic DSK images containing unformatted tracks, avoiding invalid disk images (thanks, Sergio Baldoví) (Fredrick Meunier).

### Machine-specific improvements:
* Support 8K and 16K Interface 1 ROM images, including their size in snapshots (thanks, Andy Potter) (Fredrick Meunier).
* Support the DISCiPLE on 128K machines, with an inhibit switch in Peripherals preferences (thanks, Stuart Brady, Alan Pearson and Gergely Szasz) (Sergio Baldoví and Fredrick Meunier).
* Correct +D address decoding (Fredrick Meunier).

### RZX improvements:
* Improve playback compatibility with older Fuse, Spectaculator and SPIN recordings, including interrupt timing, snapshot paging and tape-save input (Fredrick Meunier).
* Place autosave snapshots after interrupt processing for more reliable unfinalised recordings (thanks, Sergio Baldoví) (Fredrick Meunier).

### Miscellaneous improvements:
* Improve composite scaler performance and edge colours (Fredrick Meunier).
* Show pulse counts for RLE Pulse tape blocks and add the FMF extension when recording movies (Fredrick Meunier).
